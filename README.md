# Hyper TicTacToe

# Installation
1. You can download the release version (keep dlls, exe and res in same place)

# Requirement
    1. SFML-3.0.2 (Included in repository)

# Compilation Setup
    2. CMake uses msvc and ninja to build (so either use your own building system or use msvc and ninja for easy compilation)

# Features
    1. Simple but functional game (as of now not many features are available)
    2. Moves recommendations system (Minimax (not fully optmiized))
